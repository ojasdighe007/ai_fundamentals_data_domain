- Used for translation tasks since mapping each word to its correct semantic meaning requires richer contextual understanding to be attended for every word, not only last word which happens in decoder-only transformer
- Architecturally, decoder-only generates the contextual embedding, then takes contextual embedding generated by encoder-only. Uses cross attention mechanism to generate hybrid contextual embedding which is fed to LM Head for next token prediction. And then iteratively repeates this process till end charachter is generated by Decoder-Only transformer.
